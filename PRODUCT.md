# Product

## Register

product

## Users

Developers and operators who manage remote servers from macOS. They use uTerm to connect over SSH, work in terminal sessions, browse and edit remote files, manage tunnels and keys, and ask an AI assistant for help without leaving the workspace.

## Product Purpose

uTerm is a native macOS server workspace that combines SSH terminals, SFTP file workflows, connection management, port forwarding, and contextual AI assistance. Success means users can move between these tasks quickly while the interface remains predictable, responsive, and recognizably Mac-native.

## Brand Personality

Focused, precise, and calm. The product should feel like a dependable developer tool: dense when the work requires it, restrained in decoration, and clear about connection and safety state.

## Anti-references

- Web-dashboard chrome that feels foreign on macOS.
- Decorative glass, blur, gradients, or motion that competes with terminal content.
- Generic card-heavy SaaS layouts and oversized controls that reduce working density.
- Visual inconsistency between workspace, terminal, file, settings, and management windows.

## Design Principles

- Keep the tool subordinate to the task: terminal and file content remain primary.
- Preserve native macOS behavior and familiar interaction patterns wherever possible.
- Use one consistent DesignKit vocabulary across every window and state.
- Communicate connection, safety, focus, and selection states unambiguously.
- Prefer small, owning-seam fixes over broad visual churn.

## Accessibility & Inclusion

Respect macOS accessibility settings and system appearance, provide meaningful VoiceOver labels for icon-only controls, never rely on color alone for important state, preserve keyboard workflows, and keep motion brief and state-driven with reduced-motion behavior where animation is used.
